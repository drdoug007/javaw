Java to WebAssembly (javaw) Showcase

Explore native browser DOM manipulation, 2D canvas simulations, 128-bit SIMD math, WASI interactive terminal, and GraalVM-style JavaScript interop authored entirely in Java.

Demonstrates: Strongly-typed Java DOM facades (DOM, Element), dynamic string concatenation, array queries, and interactive DOM event handlers compiled to WebAssembly.
// Java DOM Source (TodoApp.java) Element root = DOM.getElementById("todo-app"); Element btn = DOM.createElement("button"); btn.setInnerText("Add Task"); btn.addEventListener("click", "addTodo"); root.appendChild(btn);
Demonstrates: HTML5 Canvas 2D hardware-accelerated drawing primitives (CanvasRenderingContext2D), linear memory grid state buffers, and dynamic rendering loops.
// Java Canvas 2D Source (GameOfLife.java) CanvasRenderingContext2D ctx = DOM.getCanvasContext2D("life-canvas"); ctx.setFillStyle("#10b981"); ctx.fillRect(x * CELL_SIZE, y * CELL_SIZE, CELL_SIZE, CELL_SIZE);
Demonstrates: Fixed-width 128-bit SIMD vectorization facades (Float32x4), integrating 4 parallel coordinates simultaneously using native WebAssembly v128 instructions.
// Java SIMD Source (SimdParticles.java) Float32x4 posX = Float32x4.of(50.0f, 120.0f, 200.0f, 320.0f); Float32x4 velX = Float32x4.of(2.5f, -3.0f, 1.8f, -2.2f); posX = posX.add(velX); // Emits f32x4.add WebAssembly vector instruction
Demonstrates: GraalVM Web Image-style @JS inline JavaScript snippet evaluation, automatic type coercion (@JS.Coerce), and standard JavaScript global facades (JSDate, JSMath, JSJSON, JSStorage).
// Java @JS Annotation Source (JsInteropShowcase.java) @JS("return Math.hypot(a, b);") public static native double calculateHypotenuse(@JS.Coerce double a, @JS.Coerce double b);
Demonstrates: Interactive in-browser WASI Terminal (WASITerminal, Terminal), ANSI 16-color styling, interactive standard input stream reading, and Virtual File System (WASIFile).
// Java WASI Terminal Source (WasiShellDemo.java) Terminal.println(Terminal.BRIGHT_CYAN + "=== Javaw Interactive Shell ===" + Terminal.RESET); String cmd = Terminal.readLine("wasi-sh> "); WASIFile file = new WASIFile("welcome.txt");
Demonstrates: Bytecode-to-WebAssembly Relooper control flow structuring (Euclidean GCD, Fibonacci, Collatz conjecture, Prime Sieve, and multi-state Lexer switch dispatch) with local ~/.m2 repository caching.
// Java Bytecode Algorithm Source (BytecodeAlgorithmsDemo.java) public static int gcd(int a, int b) { while (b != 0) { int temp = b; b = a % b; a = temp; } return a; }
Demonstrates: Enterprise org.apache.logging.log4j logging in WebAssembly with multi-logger management (LogManager), ThreadContext MDC diagnostics, parameterized formatting, and real-time UI log streaming.
// Java Log4j2 Logging Source (Log4j2Demo.java) private static final Logger logger = LogManager.getLogger(Log4j2Demo.class); ThreadContext.put("traceId", "req-8f4b-101"); logger.info("User session established for userId: {}", "usr_49201"); logger.warn("Payment response delayed (latency: {} ms)", 480); logger.error("Query timeout on partition: {}", "sh_europe_04");
