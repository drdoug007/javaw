The game rules, drone behaviors, collisions, scoring and every draw and sound command are decided in Java, compiled by javaw-bytecode with its bundled runtime. The page maps those commands to the canvas and WebAudio, and handles input, timing, the banners and the stored best score. Each drawing call is a static native method bound with --native-import to a Wasm import that this page supplies (canvas.rect, canvas.circle, audio.tone, …); only numbers cross. The page calls the exported nebula.Nebula.update and render at 60 Hz and collects the managed heap between frames.
