NEBULA RUN

A Java game, running in your browser as WebAssembly

Steer a comet through a neon maze, gather stardust, and stay ahead of four drones. The game rules are plain Java. javac compiles them, and javaw-bytecode turns the class files into WebAssembly. No JVM, no plugin, no server.

How to play

Controls

Steer with the arrow keys or WASD. Enter or Space starts and pauses, and M toggles sound. On a phone or tablet, use the on-screen pad or swipe on the maze.

Score

Stardust is worth 5 and a nova core 25. A nova core dims the drones for a while, and a dimmed drone is worth 150 × your combo. A crystal, worth 250 × the sector, appears twice per sector.

The drones

Vex chases you and is a little faster. Lumen waits at your next junction. Drift roams, and Bastion guards the east nova core. The tunnel wraps from top to bottom.

Each drawing call is a static native Java method. The --native-import option binds it to a WebAssembly import such as canvas.rect, canvas.circle or audio.tone, and the page supplies each import as a small JavaScript function. Only numbers cross the boundary: coordinates, colors, the score, lives and tone frequencies. The page runs the exported update function in fixed 60 Hz steps, calls render once per animation frame, and then runs the module's garbage collector.

The Java side uses interfaces and virtual dispatch, a lambda, nested classes, ArrayList with enhanced for loops, switch expressions, long arithmetic, string concatenation, Arrays.fill and Math. All of it runs on javaw-bytecode's bundled runtime and its managed heap.

Checked against the JVM

Every build of this site plays the same game twice: once on the JVM and once as WebAssembly in Node. Both runs use a fixed seed and a deterministic autopilot for 20,000 frames, covering deaths, cleared sectors, game overs and restarts. Each run hashes every draw and sound command it produces, about 1.2 million of them. The site is published only if the two hashes match. The project's test suite runs a shorter 6,000-frame version of the same comparison.

Current limits

  • nebula.wasm is about 700 KB and not yet optimized. Most of it is runtime code pulled in by string concatenation and collections.
  • Only numbers cross between Java and the page, so the page draws the HUD text.
  • The bundled runtime has no System.out, so the JVM entry point used for the comparison lives outside the WebAssembly build.
  • javaw is a work in progress. It does not support every Java or JDK feature yet. This game shows a tested subset.
Nebula Run is an original game built as a demo for javaw, a Java-to-WebAssembly compiler. See the example's README for build instructions.
