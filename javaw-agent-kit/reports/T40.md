# T40 BufferedWriter
Implemented: `java.io.BufferedWriter` with `BufferedWriter(Writer)`, `BufferedWriter(Writer, int)`, `ensureOpen()`, `flushBuffer()`, `write(int)`, `write(char[], int, int)`, `write(String, int, int)`, `newLine()`, `flush()`, and `close()`.
Left out: `growIfNeeded(int)` and `maxChars` (as per task instructions to avoid buffer growth).
Notes: Followed JDK 21 behavior for constructor exceptions, `write(int)` flushing, and `close()` exception suppression.
