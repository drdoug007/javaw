# T82 java.time.LocalTime

Implemented: `java/time/LocalTime.java` — final class with `byte hour/minute/second` + `int nano`, the
`HOURS` cache filled in a `static {}` block before `MIN`/`MAX`/`MIDNIGHT`/`NOON`, a `create` helper that
returns the cached whole hours, `of(II/III/IIII)`, `ofSecondOfDay`, `ofNanoOfDay`, `parse(CharSequence)`,
the four getters, `toSecondOfDay`/`toNanoOfDay`, the four `withX`, the eight `plusX`/`minusX` (wrap-around
formulas with the remainder taken before adding), `compareTo`/`isBefore`/`isAfter`/`equals`/`hashCode`
(`Long.hashCode(toNanoOfDay())`), the JDK ISO `toString` (3/6/9-digit fraction), and a hand-written strict
ISO_LOCAL_TIME parser (two-digit fields, optional seconds, 0-9 digit right-padded fraction, unparsed-text
before value checks, minute-before-hour value validation, JDK `DateTimeParseException` messages with 64-char
abbreviation).

Left out: `now` (no clock), `from`/`get`/`getLong`/`isSupported`/`range`/`with(TemporalField, long)`/
`with(TemporalAdjuster)`/`plus`/`minus(TemporalAmount, long, TemporalUnit)`/`truncatedTo`/`until`/`query`/
`adjustInto` (no `Temporal`/`TemporalAccessor`/`TemporalAdjuster`/`TemporalUnit`/`TemporalAmount` types),
`atDate`/`atOffset`/`ofInstant`/`toEpochSecond` (no `LocalDate` combination/`ZoneOffset`/`ZoneId`),
`format`/`parse(CharSequence, DateTimeFormatter)` (no `DateTimeFormatter`), and the serialization proxy.
`equals`/`hashCode`/`toString` and the arithmetic make the value type coherent for the Jackson/H2/Spring
call sites the audit lists.

Notes: two calibration surprises. (1) `compareTo` uses `Integer.compare` for the nano field too — the JVM
returns 1 (not the raw 1000 difference) for `of(5,30,0,1000).compareTo(of(5,30))`, which the fixture prints
directly. (2) The `toString` fraction branch tests `nano % 1_000_000`/`nano % 1_000`, not the truncated
`nanos1000` value — with `nanos1000` the sub-millisecond nanos collapsed to a 3-digit `".000"`. Also the
`'10:'` syntax case: the `:` check must pass for a present delimiter (`len < 3`, not `len <= 3`) so the
missing minute reports index 3, not 2.
