# T19 ByteArrayOutputStream

Implemented: `java.io.ByteArrayOutputStream` (extends the runtime `java.io.OutputStream`) with protected
`buf`/`count`, both constructors, `write(int)`, `write(byte[],int,int)`, `writeBytes`, `writeTo`, `reset`,
`toByteArray`, `size`, `toString()`/`toString(String)`/`toString(Charset)`/`toString(int hibyte)`, no-op
`close()`, and the private `ensureCapacity` helper with the JDK growth rule.

Left out: nothing else exists on the JDK 21 class. Per the task, `write(byte[])` and `flush()` are not
overridden (the inherited `OutputStream` versions are used), and no `Objects.checkFromIndexSize` was added —
the range check is written inline without `off + len` overflow.

Notes: kit check passed on the first run (38 new lines in the runtime class). The only subtlety worth noting
is that `write(byte[],int,int)` must do its own `System.arraycopy` rather than delegate to the inherited
per-byte loop, otherwise a 10-byte write from capacity 3 grows the buffer one byte at a time (to 12 instead
of 10) and `growthByArray` fails.
