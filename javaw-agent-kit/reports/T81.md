# T81: java.time.LocalDate (core subset) + marker ChronoLocalDate

Implemented: `java.time.LocalDate` (final class implementing the marker `java.time.chrono.ChronoLocalDate` and `java.io.Serializable`) with the constants MIN/MAX/EPOCH; factories `of(int,int,int)`, `of(int,Month,int)` (null month → NPE "month"), `ofYearDay`, `ofEpochDay`, all with the exact JDK DateTimeException messages (Year/MonthOfYear/DayOfMonth/DayOfYear/EpochDay range text, `Invalid date '<MONTH> <day>'`, `Invalid date 'February 29' as '<year>' is not a leap year`, `Invalid date 'DayOfYear 366' as '<year>' is not a leap year`); getters getYear/getMonthValue/getDayOfMonth/getMonth/getDayOfWeek/getDayOfYear/isLeapYear/lengthOfMonth/lengthOfYear; `toEpochDay`/`ofEpochDay` with the JDK 400-year-cycle algorithms in long arithmetic (DAYS_PER_CYCLE 146097, DAYS_0000_TO_1970 719528); `plusYears/plusMonths/plusWeeks/plusDays` and the four minus forms (month-end clamping via resolvePreviousValid, zero amount returns `this`, Long.MIN_VALUE handled by the plus(MAX)+1 idiom); `plus/minus(long, TemporalUnit)` for DAYS, WEEKS, MONTHS, YEARS, DECADES, CENTURIES, MILLENNIA (last three via `Math.multiplyExact`) and UnsupportedTemporalTypeException for every other unit; withers `withYear/withMonth/withDayOfMonth/withDayOfYear`; `compareTo(ChronoLocalDate)` returning the raw year/month/day differences, `isAfter/isBefore/isEqual`, `equals`, the JDK `hashCode`, and the JDK ISO `toString`. Also `java.time.chrono.ChronoLocalDate` — the exact 4-line marker interface extending `Comparable<ChronoLocalDate>` with no methods.

Left out: `now`, `parse`, `format`, `from`, `atStartOfDay`, `atTime`, `ofInstant`, `until`, `datesUntil` (no clock/text/LocalDateTime bridging); `with(TemporalAdjuster)`, `with(TemporalField,long)`, `get`, `getLong`, `range`, `query`, `adjustInto`, `isSupported`, `getChronology`, `getEra` (no Temporal/TemporalAccessor/TemporalAdjuster interfaces — LocalDate implements none of them and ChronoLocalDate declares no members of its own, so those interface calls stay unlinked); `plus/minus(TemporalAmount)` and ERAS/FOREVER/time-based units (UnsupportedTemporalTypeException); serialization hooks.

Notes: the JDK `toString` prints an explicit plus for years above 9999 (`+10000-02-29`, `+999999999-12-31`); the ±10000/deleteCharAt zero-padding trick is only valid for |year| ≤ 999, and that was the one behavioral fix during the loop (first run produced `+0000-02-29` for year 10000). Year 10000 is a valid leap-year date (`leap.plusYears(7976)` = `10000-02-29`), not an overflow. `compareTo` returns raw differences (e.g. MIN vs MAX = -1999999998), matching the JDK `compareTo0`. `MAX.plusDays(1)` reports a Year overflow (year 1000000000), not an EpochDay overflow, because of the plusDays fast path. `UnsupportedTemporalTypeException` lives in `java.time.temporal` (not `java.time`) and needed an import; `monthLength` takes a boolean leap flag, which the first draft got wrong.
