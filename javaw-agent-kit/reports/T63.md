# T63 java.util.Date millisecond core

Implemented: `java.util.Date` as a wrapper around `private transient long fastTime` — `Date(long)`,
`getTime`/`setTime`, `before`/`after`, `compareTo` (with the javac raw bridge), `equals`, `hashCode`
(`(int) ht ^ (int) (ht >> 32)`, signed shift, one virtual `getTime()`), `clone` (`super.clone()` in
try/catch), the package-private `getMillisOf`, and `toInstant`/`from(Instant)` with the
`ArithmeticException` -> `IllegalArgumentException(ex)` wrapping. `Date` implements `java.io.Serializable`,
`Cloneable`, `Comparable<Date>`.

Left out: `Date()` (reads the wall clock — no host clock contract yet), `toString`/`toGMTString`/
`toLocaleString` (need `TimeZone`/calendar code; inherited `Object.toString` stays), the deprecated field
constructors/accessors, `parse`, `UTC`, the `cdate` field, `normalize`, `getCalendarSystem` and
`writeObject`/`readObject` (calendar/serialization machinery not in the runtime).

Notes: first check passed without fixes. Kept `getMillisOf` exactly as the JDK writes it so
`before(null)`/`after(null)`/`compareTo(null)` throw `NullPointerException` from `getClass()`, and kept
`equals`/`hashCode` on virtual `getTime()` calls so the Spy-subclass call log matches (e.g. `getA;` for
`a.equals(p)`, empty log for `a.equals("x")`).
