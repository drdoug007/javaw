# T73 LongStream and DoubleStream

Implemented: `java/util/stream/LongStream.java`, `LongPipeline.java`, `DoubleStream.java`, `DoublePipeline.java`
(registered with `kit register`); `PrimitiveIterator.OfLong` and `PrimitiveIterator.OfDouble` added to the existing
`PrimitiveIterator.java`; `Stream.mapToLong`/`mapToDouble` added to `Stream.java` and implemented in
`ReferenceStream.java` next to `mapToInt`. Long factories (`empty`, `of`, `range`, `rangeClosed`), filter/map/peek,
distinct/sorted/limit/skip, mapToObj/boxed, the match/find terminals, toArray/count/reduce, `sum` (`reduce(0, Long::sum)`),
`min`/`max` (`Math.min`/`Math.max`), `average` (wrapping `long` total divided as `double`), and the JDK compensated
(Kahan) `DoubleStream.sum`/`average` via private static `sumWithCompensation`/`computeFinalSum` helpers.

Left out: `summaryStatistics`, `collect`, `flatMap`, `takeWhile`/`dropWhile`, `generate`/`iterate`/`concat`, the
cross-primitive conversions (`LongStream.mapToInt`/`mapToDouble`/`asDoubleStream`, `DoubleStream.mapToInt`/`mapToLong`),
`builder`/`spliterator` and `Random.longs` — none is referenced by the pinned libraries; `IntStream` was not touched,
so `asLongStream`/`asDoubleStream` stay unlinked. `parallel()` throws `UnsupportedOperationException`.

Notes: `range`/`rangeClosed` walk `first..last` inclusive with a `done` flag set after returning `last` (never
`end + 1`, which overflows at `Long.MAX_VALUE`); `position++` may wrap after emitting the last element but `hasNext`
checks `done` first. First `kit check` failed with a javac error — `DoublePipeline.sum`/`average` called
`v.doubleValue()` on the primitive `double` argument of their own `forEach(DoubleConsumer)`; fixed by using `v`
directly. PASS on the second attempt.
