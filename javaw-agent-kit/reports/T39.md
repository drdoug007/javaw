# T39 UncheckedIOException and BufferedReader.lines()
Implemented: `java/io/UncheckedIOException.java` with both constructors (`super(Objects.requireNonNull(cause))`
and `super(message, Objects.requireNonNull(cause))`) and the covariant `getCause()`; `BufferedReader.lines()`
exactly the JDK 21 anonymous-Iterator code over `StreamSupport.stream(spliteratorUnknownSize(iter, ORDERED |
NONNULL), false)`. Registered `java/io/UncheckedIOException.java` via `kit register`.
Left out: `readObject`/`serialVersionUID` (no serialization, `ObjectInputStream` not in the runtime).
Notes: `UncheckedIOException` needs `import java.util.Objects;` — `Objects` does not resolve unqualified from
`java.io`. Wasm-side `Objects.requireNonNull` throws a messageless `NullPointerException` (the JDK uses the
string `"null"`), but the observed `getSimpleName()+":"+getMessage()` output is identical in both, so the
differential matches. Kit check passed on the first run.
