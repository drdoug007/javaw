# T03 ArrayList index failure messages

Implemented: 
- `AbstractList.index(int)` with message "Index "+index+" out of bounds for length "+size()
- `AbstractList.position(int)` with message "Index: "+index+", Size: "+size()  
- `AbstractList.subList(int,int)` with three separate checks in order:
  1. `from<0` → `IndexOutOfBoundsException("fromIndex = "+start)`
  2. `to>n` → `IndexOutOfBoundsException("toIndex = "+end)`  
  3. `from>to` → `IllegalArgumentException("fromIndex("+start+") > toIndex("+end+")")`
- `ArrayList(int)` constructor with message "Illegal Capacity: "+capacity

Left out: 
- `ArrayList.removeRange(int,int)` (not required by the task)
- `java.util.Objects.checkIndex(int,int)` (not to be added per task requirements)
