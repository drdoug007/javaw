# T17 Base64
Implemented: `java.util.Base64` with `getEncoder`, `getUrlEncoder`, `getMimeEncoder()`/`(int, byte[])`,
`getDecoder`, `getUrlDecoder`, `getMimeDecoder`; `Base64.Encoder` (`encode(byte[])`, `encode(byte[], byte[])`,
`encodeToString`, `withoutPadding`); `Base64.Decoder` (`decode(byte[])`, `decode(String)`, `decode(byte[],
byte[])`). Encode tables from the alphabet strings, decode tables `int[256]` with `-1`/`-2` markers, the
shift-to decoder with the MIME skip/trailing-byte quirks, and the exact `IllegalArgumentException` messages.
Left out: `Encoder.wrap(OutputStream)`, `Decoder.wrap(InputStream)`, `Encoder.encode(ByteBuffer)`,
`Decoder.decode(ByteBuffer)` — the task requires them to stay unlinked, and the admission test
`leavesStreamsAndByteBuffersUnlinked` rejects calls to them before WAT generation.
Notes: first check failed only on a javac symbol error — runtime sources use fully-qualified names, so
`decode(String)` needed `src.getBytes(java.nio.charset.StandardCharsets.ISO_8859_1)` instead of an unqualified
`StandardCharsets`. Second check: PASS, all six tests.
