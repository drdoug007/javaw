# T44 LineNumberReader
Implemented: `java.io.LineNumberReader` (new file, registered) with both constructors, `setLineNumber`,
`getLineNumber`, `read()`, `read(char[],int,int)`, `readLine()`, `skip(long)`, `mark(int)`, `reset()`; and the
package-private `BufferedReader.readLine(boolean, boolean[])` split out of `BufferedReader.readLine()`, which
now delegates with `(false, null)`.
Left out: `lines()` (stays unlinked, per T32); `close()`/`ready()`/`markSupported()`/`read(char[])`/
`transferTo(Writer)` are inherited, not overridden. No locks (the JDK's `synchronized (lock)` wrappers are
dropped; the pinned code is single-threaded).
Notes: passed `kit check T44` and the T32 regression on the first attempt. Behaviours worth remembering:
end-of-input adds a line only when `prevChar == CHAR`, in all three read methods; `skip` sets `prevChar = NONE`
when it skipped anything; `mark` increments the read-ahead limit by 1 after a `\r` (so `mark(Integer.MAX_VALUE)`
overflows to negative and throws).
