# T45 Seeded Random

Implemented: `java/util/Random.java` — `Random(long)`, `initialScramble`, `setSeed`, `next(int)`, `nextBytes`,
`nextInt()`, `nextInt(int)`, `nextInt(int,int)`, `nextLong()`, `nextBoolean()`, `nextFloat()`, `nextDouble()`,
`nextGaussian()`; the 48-bit LCG with the JDK constants. Registered via `kit register`.

Left out: `Random()` (time/entropy, forbidden by `kit guard`), `ints`/`longs`/`doubles` streams (need
`RandomSupport` spliterators), the other `RandomGenerator` defaults (`nextLong(long)`, `nextLong(long,long)`,
`nextFloat(float...)`, `nextDouble(double...)`, `nextExponential`, `nextGaussian(double,double)`,
`isDeprecated`), `Random.from`/`RandomWrapper`, and serialization. `Random` does not implement
`java.util.random.RandomGenerator` (not in the runtime); the seed is a plain `long`, methods are not
`synchronized`.

Notes: passed `kit check` on the first run. `nextGaussian` keeps the JDK's local `double multiplier`, which
shadows the static field of the same name; the task spec notes this is fine.
