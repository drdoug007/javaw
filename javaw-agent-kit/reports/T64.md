# T64 Timed CountDownLatch.await and Semaphore.tryAcquire

Implemented: `CountDownLatch.await(long, TimeUnit)` in `CountDownLatch.java`; `Semaphore.tryAcquire(long,
TimeUnit)` and `Semaphore.tryAcquire(int, long, TimeUnit)` in `Semaphore.java`. Each evaluates
`unit.toNanos(timeout)` first (null unit -> NPE, state unchanged), then returns the untimed result directly
from the fields/private helpers (`count == 0`, `tryTake(1)`, `tryTake(n)` after `checkNonNegative(n)`).
`tryAcquire(int, long, TimeUnit)` checks `permits < 0` (IllegalArgumentException, message null) before the
unit check.

Left out: `Semaphore.hasQueuedThreads`, `getQueueLength`, `getQueuedThreads` (no queued threads in the
single-threaded contract; `getQueuedThreads` needs `Thread`) and `TimeUnit.sleep` (T52 owns that file) — all
checked as rejected by `leavesOutQueuesAndThreads`.

Notes: `kit check T64` passed on the first attempt. Timed members call only private helpers, so the
`LatchSpy`/`SemSpy` call-pattern logs stay empty; no overridable self-calls.
