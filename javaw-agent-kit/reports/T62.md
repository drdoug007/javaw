# T62 ClassNotFoundException

Implemented: `java.lang.ClassNotFoundException` (new runtime file, registered) with the three constructors
`()`, `(String)`, `(String, Throwable)` and `getException()`; added the two missing cause constructors
`ReflectiveOperationException(String, Throwable)` and `(Throwable)` to the existing runtime class.

Left out: `readObject`/`writeObject`/`serialPersistentFields` (serialization; `java.io.ObjectInputStream` is
not linked). No `ClassNotFoundException(Throwable)` constructor — it does not exist in the JDK. No
`Class.forName` or any class lookup.

Notes: `kit check` passed on the first attempt. Key JDK behaviour: every `ClassNotFoundException` constructor
sets the cause (the no-arg one via `super((Throwable) null)`), so `initCause` throws
`IllegalStateException` in all cases; `getException()` uses `super.getCause()` so a subclass `getCause`
override is not invoked.
