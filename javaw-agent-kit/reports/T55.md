# T55 Semaphore

Implemented: `java.util.concurrent.Semaphore` (single-threaded) — both constructors (any int, fair flag),
`acquire()`/`acquire(int)`, `acquireUninterruptibly()`/`acquireUninterruptibly(int)`, `tryAcquire()`/
`tryAcquire(int)`, `release()`/`release(int)`, `availablePermits()`, `drainPermits()`, protected
`reducePermits(int)`, `isFair()`, `toString()`, with private helpers `checkNonNegative`, `tryTake`, `take`
and `give`. IllegalArgumentException (null message) on negative arguments; `Error("Maximum permit count
exceeded")` on release overflow (`next < permits`); `Error("Permit count underflow")` on reduce overflow
(`next > permits`); `drainPermits` zeroes even a negative count; the would-block `acquire` path throws
IllegalStateException per the single-threaded contract.

Left out: timed `tryAcquire(long, TimeUnit)` / `tryAcquire(int, long, TimeUnit)` (TimeUnit dependency,
positive timeout would have to sleep), queue inspection `hasQueuedThreads` / `getQueueLength` /
`getQueuedThreads` (no queued threads exist; `getQueuedThreads` needs `Collection<Thread>`), and all JDK
internals (`Sync`, `NonfairSync`, `FairSync`, `AbstractQueuedSynchronizer`).

Notes: `BytecodeSemaphoreTest` passed on the first `kit check` run. `release()` and the one-argument
`acquire`/`tryAcquire` duplicate the one-permit logic inline through the private helpers so no public
method ever dispatches to another overridable method of `this` (the Spy fixture logs every call).
