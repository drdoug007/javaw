# T60 ChronoUnit
Implemented: `java/time/temporal/TemporalUnit` (interface: `getDuration`, `isDurationEstimated`, `isDateBased`, `isTimeBased`, `toString`), `java/time/temporal/UnsupportedTemporalTypeException` (extends `java.time.DateTimeException`, `(String)` and `(String,Throwable)`), `java/time/temporal/ChronoUnit` (16 constants in JDK order, display-name + duration fields, `toString()` = display name, estimated = `compareTo(DAYS) >= 0`, date-based excludes `FOREVER`), `Duration.of/plus/minus(long, TemporalUnit)` (null check → `DAYS` multiplyExact-by-86400 special case → estimated-unit `UnsupportedTemporalTypeException` even for amount 0 → zero returns `this` → `NANOS`/`MICROS`/`MILLIS`/`SECONDS` switch, other `ChronoUnit` via `multiplyExact(unit.getDuration().seconds, amount)`, other units via `multipliedBy`; `minus(Long.MIN_VALUE, u)` = `plus(MAX, u).plus(1, u)`), and `TimeUnit.toChronoUnit()`/`TimeUnit.of(ChronoUnit)` (seven-way mapping; `of` throws NPE `chronoUnit` on null and `IllegalArgumentException("No TimeUnit equivalent for " + unit)` — display name — otherwise).
