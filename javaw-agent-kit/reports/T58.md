# T58 AssertionError
Implemented: `java.lang.AssertionError` in the bundled bytecode runtime: no-arg constructor, private
`AssertionError(String)` helper, `Object`/`boolean`/`char`/`int`/`long`/`float`/`double` constructors and
`(String, Throwable)`.
Left out: `Class.desiredAssertionStatus()` and the rest of the assertion-status API, per the task —
`assert` statements are still rejected (a later task needs a host contract for `-ea`). No other members
were left out; the remaining public constructors (`char`, `float`, `double`, `(String, Throwable)`) have
no audit rows but are included so the class matches the JDK API as a whole.
Notes: none. The `Object` constructor must not pass the detail to `super(message, cause)` (that would skip
the virtual `initCause` call the test counts) and must not call `initCause` for non-Throwable details
(that would set the cause to `null` and make a later `initCause` throw); `kit check` printed PASS on the
first attempt.
