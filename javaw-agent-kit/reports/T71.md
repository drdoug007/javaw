# T71 Enum.valueOf for every enum

Implemented: `java.lang.Enum` registry fields `javawTypes`/`javawConstants`/`javawCounts`,
`javawRegister` (called from the constructor, keyed by `getDeclaringClass()`), and a rewritten
`valueOf(Class, String)` with the JDK check order (null class NPE, `is not an enum class`
IllegalArgumentException via `getName()`, `Name is null` NPE, exact `name()` scan, `No enum constant`
IllegalArgumentException via `getCanonicalName()`). Unregistered classes (empty application enums)
fall back to `getEnumConstants()`. Docs in `docs/bytecode-enum-value-of.md`.

Left out: `Class.enumConstantDirectory` (JDK-private; `getEnumConstants()` untouched, per task).
Per the task's "Members to leave out", no public helpers added to `Enum`.

Notes: passed on the first check. Registering under `getDeclaringClass()` (not `getClass()`) is
what makes the `GREEN { ... }` constant body case work.
